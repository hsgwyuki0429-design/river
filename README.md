# River — 川の、長い時間を。

蛇行が育ち、首がつながり、三日月湖が残る。自然な川の**変遷を早送りで観察する**ブラウザアプリです。
PC・スマートフォンで、起動するとすぐに川が動き始めます。

## 観察できること

- 曲率と上流の影響から毎ステップ計算する河岸移動、蛇行の成長、幾何条件による流路切断。
- 草原・砂地・森の3環境。流量と川岸の変わりやすさを調整でき、20モデル年の増水も試せます。
- 5 / 20 / 80 年毎秒の早送り、一時停止、100年送り。上限は1,200モデル年です。
- 過去の流路の重ね表示、時間軸での巻き戻しと再生、流路長・蛇行度・三日月湖の記録。
- 地形を盛る・削る・ならす操作。高くした岸を避け、掘った低地へ川が寄る変化を観察できます。
- 現在表示している川と地形のブラウザ内保存・復元、PNG画像の保存。

年数は**未校正のモデル時間**です。実在の川の過去の再現や将来予測ではありません。
川幅は流量に応じて一様に設定し、水深・土砂収支・洪水の浸水域は計算しません。
編集した地形の高さは河岸移動の計算に使用します。砂州、流れの矢印、旧流路の緑化と背景の細い模様は説明のための表現です。
高い地形の侵食・決壊や、掘削による瞬間的な水路の付け替えは計算しません。
方式と制約は画面の「このモデルについて」と [モデルの説明](docs/observatory.md) に記載しています。

## 操作

| 操作 | 内容 |
| --- | --- |
| 再生ボタン / Space | 再生と一時停止 |
| 早送り | モデル時間の進む速さを変更 |
| 100年進める | 最新の川から100年進めて停止 |
| 時間軸 | 記録済みの過去を観察。再生すると過去の記録から続けて見る |
| 最新へ | 現在の川へ戻る |
| 盛る / 削る / ならす | 観察を止めて地形を編集。なぞるか、地図にフォーカスして矢印キー＋Enterで操作 |
| ブラシ / 強さ | 変更範囲と1回あたりの高さを指定（全体の変更量は−12〜+12 m） |
| ひと筆戻す / 地形を戻す | 直近20回まで地形編集を戻す / 川の形を保ったまま地形を初期化 |
| 川の環境 / はじめから | 選択した環境で初期状態から観察 |
| 保存 / 復元 | このブラウザに現在表示中の川と地形を保存。復元は保存時点から再開 |
| カメラ | 現在の風景をPNGで保存 |

保存は手動です。過去の記録全体は保存せず、復元後の時間軸は保存時点から始まります。
地形編集の前後も時間軸に記録します。過去の地形は編集後も保たれます。「再生」で編集を終え、新しい地形に応じた川の変化を観察できます。
OSの「視差効果を減らす」設定では停止状態で起動します。タブが隠れている間は時間を進めません。
画面サイズ・再生速度によって積分刻みを変更しないため、同じ初期状態と設定は同じ結果になります。

## 砂の実験室

以前の砂を盛る・削る操作、5つのお題、自由モードと格子型の蛇行観察は
右上の「砂の実験室」（`?mode=sandbox`）から利用できます。
元のシミュレーションと保存データの形式は維持しています。
詳細は [砂の実験室の説明](docs/sandbox.md) を参照してください。

## 開発と検証

```bash
npm ci
npm run dev
npm run typecheck
npm test
npm run build
npm run preview

# previewを起動した状態で実ブラウザを確認
npm run smoke -- ./tmp
npm run smoke:legacy -- ./tmp
npm run smoke:terrain -- ./tmp
```

Playwright用ブラウザは `npx playwright install chromium` で用意するか、
`PW_CHROMIUM` に既存Chromiumの実行ファイルを指定します。
`BASE_URL` で配信先を変更できます。既存の性能テストはホスト負荷に敏感なので、
性能だけを計測するときは `npx vitest run test/performance.test.ts` で単独実行してください。

新モデルのテストは蛇行・切断、直線河道での無イベント、設定への応答、
3環境の1,200年安定性、保存後の完全に同じ継続、不正データの拒否を確認します。
ブラウザテストはPC / iPhone幅、再生・過去の観察・最新復帰・保存復元・画像保存を確認します。

## 構成

- `src/main.ts`：観察アプリと砂の実験室の遅延読み込み。
- `src/observatory/model.ts`：DOMに依存しない中心線の移動・流路切断・保存検証。
- `src/observatory/terrain.ts` / `terrain-input.ts`：高さ格子とブラシ編集、マウス・タッチ・キーボード入力。
- `src/observatory/renderer.ts`：計算状態を読み取るCanvas描画。
- `src/observatory/app.ts` / `style.css`：観察画面、記録、再生操作。
- `src/legacy-main.ts`、`src/sim/`、`src/game/`、`src/render/`、`src/ui/`：従来の実験室。

## 公開

既存の GitHub Pages 構成を使用します。`main` へのpushで
`.github/workflows/deploy.yml` がビルドし、`dist/` を配信します。
Viteの入力HTMLをそのまま配信せず、PagesのSourceは **GitHub Actions** に設定してください。
`base: './'` により `/river/` 以下でもアセットを相対参照します。
